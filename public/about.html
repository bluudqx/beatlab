ABOUT
PROJECT

BEATLAB — это веб-платформа для создания музыки, прослушивания треков и обмена опытом между битмейкерами.

Проект разработан в рамках курсовой работы. Основная цель — предоставить начинающим музыкантам бесплатный инструмент для создания битов прямо в браузере, без установки сложного программного обеспечения.

На сайте реализованы: система регистрации, загрузка треков, библиотека с плеером, а также интерактивная студия (секвенсор), где можно создавать собственные ритмы и сохранять их в личном кабинете.

Разработчик: Аминат Шартан

Стек технологий

  • Frontend HTML5, CSS3, JavaScript
  • Backend Node.js, Express
  • База данных SQLite3
  • Аудио-движок Web Audio API
  • Шифрование bcryptjs
  • Загрузка файлов Multer
